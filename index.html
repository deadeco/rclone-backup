Rclone Personal Backup

This is a personal, non-commercial OAuth application used solely by its owner to connect Rclone to the owner's Google Drive account.

Rclone runs on the owner's Windows computer. The purpose is to store and retrieve encrypted backup files generated by GrapheneOS Seedvault. This website does not host backup data or provide a public login service.

The OAuth app is independently maintained for private use and is not affiliated with Google, Rclone or GrapheneOS.
